This is a simple command-line game written in Java where users attempt to guess a randomly generated number between 1 and 100. The program provides feedback after each guess, guiding the player closer to the correct answer.

Features:
Random Number Generation: The program generates a random number between 1 and 100 for the player to guess.
Interactive Gameplay: Players can repeatedly guess the number until they get it right.

Hints Provided: The program provides hints such as:
"Your number is too large" if the guess is higher than the target.
"Your number is too small" if the guess is lower than the target.
Winning Message: Displays a congratulatory message when the correct number is guessed.

How to Play:
Run the program.
Enter a number between 1 and 100 when prompted.
Follow the hints provided by the program to adjust your guess.
Keep guessing until you find the correct number!

Requirements:
Java Development Kit (JDK) installed on your machine.
